# FrameInGoa — HH Goa 2026

A browser-based HH Goa 2026 photo-frame generator.

## Features

- Upload JPG/PNG/WEBP
- Automatic cover-style crop
- Name + stack + Builder Class
- Random Builder Class generator
- Canvas-based PNG generation
- One-click download
- X share intent
- Team frame builder
- Responsive UI

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy

Push the project to GitHub and import it into Vercel.

## Customize

The generated frame is drawn in `lib/canvas.ts`. Replace the colors, typography, shapes and text there with the official HH Goa 2026 assets/branding you are authorized to use.
